SpeciedexAPI

The open, versioned, blockchain-aware programming interface for querying, validating, submitting, streaming, exporting, and integrating data from the Speciedex ecosystem.

SpeciedexAPI provides a common machine interface to species blockchains, taxonomy, observations, geography, conservation, ecological relationships, media, scientific references, validation state, network health, releases, archives, and Bitcoin-funded data bounties.

The API may be served by a local SpeciedexCore node, a full-weight server node, an institutional deployment, a regional node, or a public SpeciedexWeb gateway. Clients can therefore choose between local verification, private institutional access, or public rate-limited services without changing the underlying protocol model.

Responses preserve provenance and protocol context wherever applicable: source identifiers, chain and block positions, object hashes, validation state, confidence, license, schema version, release state, revisions, and serving-node metadata.

SpeciedexAPI is designed for websites, applications, research tools, command-line clients, field systems, institutional software, analytical notebooks, artificial-intelligence systems, and independent scientific services.

Permanent Protocol Boundary

Homo sapiens is permanently excluded from all SpeciedexAPI species, observation, biometric, genomic, tracking, and profiling interfaces.

The API must not expose human species records, human observation datasets, facial-recognition records, human genomic profiles, identity graphs, population surveillance, or person-tracking services.
