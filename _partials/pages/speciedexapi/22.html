Project Integration

Relationship to the Speciedex Projects

Speciedex

Defines the protocol, species-chain model, shared data semantics, constitutional rules, and scientific mission exposed through the API.

SpeciedexCore

Implements node storage, validation, indexing, synchronization, authentication, and API services.

SpeciedexExplorer

Uses the API for advanced visualization, playback, comparison, mapping, provenance inspection, and analysis.

SpeciedexNet

Supplies verified chain, object, release, peer, and synchronization state to participating API nodes.

SpeciedexWeb

Uses public API gateways to provide browser access without requiring visitors to operate a node.

SpeciedexApp

Uses local or remote API services for field packages, observations, validation, synchronization, learning, and bounty workflows.
