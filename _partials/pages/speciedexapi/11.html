Representations

Data and Export Formats

JSON

Default structured representation for ordinary API requests and responses.

JSON Lines

Streaming, bulk export, event replay, archival, and pipeline-friendly serialized records.

CSV and TSV

Tabular exports for permitted flat views, analytical tools, spreadsheets, and data-processing systems.

GeoJSON

Permitted geographic features, observations, ranges, habitats, regions, and map-layer exports.

Binary Objects

Content-addressed evidence and media delivered with explicit content type, size, checksum, attribution, and access policy.

Manifests

Machine-readable inventories for releases, snapshots, exports, schemas, dependencies, objects, and signatures.

Signed Packages

Portable submission, synchronization, archival, and offline-transfer bundles with verification metadata.

Reproducible Queries

Serializable query definitions containing filters, sorting, fields, chain position, release, and pagination state.
