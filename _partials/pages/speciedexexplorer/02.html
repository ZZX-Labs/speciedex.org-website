Purpose

Advanced Interactive Discovery

Built for Deep Exploration

SpeciedexExplorer turns verified chain data into maps, taxonomic trees, record graphs, timelines, tables, comparisons, media views, provenance trails, and analytical workspaces.

It is intended for researchers, taxonomists, institutions, educators, conservationists, developers, archivists, and advanced public users.

Node-Aware Client

Explorer may connect to a local SpeciedexCore node, an institutional node, a trusted remote gateway, or a SpeciedexWeb public endpoint.

Connection state, node identity, verification scope, chain height, provider coverage, and data freshness remain visible to the user.

Read Without Flattening

The interface distinguishes canonical summaries from source assertions, disputed records, confidence levels, historical states, validation outcomes, and unresolved scientific disagreement.

Replay the Record

Users can move through a species chain block by block or event by event to see how names, evidence, classifications, ranges, and conclusions changed over time.

Compare Across Sources

Provider records can be aligned and compared without erasing their original identifiers, licenses, retrieval dates, or conflicting claims.

Work Reproducibly

Queries, filters, selected releases, chain heights, notebook state, and exports can be preserved so another user can reproduce the same view.
