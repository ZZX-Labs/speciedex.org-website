Search and Query

Unified Search

Search scientific names, common names, synonyms, identifiers, traits, descriptions, locations, references, media, validators, providers, chains, blocks, objects, and bounties.

Structured Filters

Filter by taxonomy, geography, habitat, time, evidence, source, confidence, review state, chain height, update age, media type, conservation condition, or validation outcome.

Relationship Queries

Ask questions that cross records, such as which pollinators overlap a plant range, which hosts share a parasite, or which threatened species occur within a protected area.

Historical Queries

Reconstruct what the network considered canonical at a selected chain height, release, date, source set, provider state, or review status.

Saved Queries

Store named queries with parameters, selected providers, fields, ordering, limits, visualization state, and expected output schema.

Query Export

Export a query as a reproducible definition for CLI, API, notebook, report, archive, or institutional workflow use.
