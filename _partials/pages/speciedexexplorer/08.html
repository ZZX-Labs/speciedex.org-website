Deployment

Access Paths

Local Explorer

Connect directly to a user-owned SpeciedexCore node for privacy, offline work, complete control, and local-speed analysis.

Institutional Explorer

Use a university, museum, laboratory, agency, conservation, or archive node with organization-specific collections.

Remote Explorer

Connect to a trusted SpeciedexNet gateway when local storage or node operation is impractical.

SpeciedexWeb

Use the public website for immediate browser access without installing or operating node software.

Portable Research Package

Open a signed snapshot, removable-media archive, or project package for disconnected review and reproducible teaching.

Read-Only Public Kiosk

Provide constrained educational or exhibition access without exposing administrative or submission privileges.
