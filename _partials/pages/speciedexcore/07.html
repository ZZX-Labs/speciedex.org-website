Deployment

Node Profiles

Full-Weight Server Node

Complete verified corpus, all chains, shared objects, indexes, APIs, peer services, archives, and optional public web delivery.

Research Workstation

Complete or selective local corpus with advanced query, analysis, visualization, export, validation, and contribution tools.

Institutional Node

Public Speciedex data combined with authorized local collections, repositories, review teams, and controlled publishing workflows.

Regional Node

Prioritizes selected geography, languages, taxa, media, providers, and field programs while remaining compatible with the global protocol.

Field Node

Operates with intermittent connectivity, queues signed submissions, verifies local packages, and synchronizes when a trusted path becomes available.

Gateway Node

Provides rate-limited APIs, cached records, validation endpoints, streaming feeds, or web access without granting upstream authority.

Archive Node

Prioritizes historical chains, snapshots, release packages, provider archives, media references, manifests, and recovery verification.

Application Node

Provides a local trusted backend for SpeciedexWeb, Explorer, Terminal, Maps, Analysis, App, and third-party integrations.
