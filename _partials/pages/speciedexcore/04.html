Data Architecture

Storage and Verification

Species Chain Store

Maintains block headers, entries, signatures, schemas, ancestry, checkpoints, fork state, and canonical state for every locally followed species chain.

Object Store

Maintains content-addressed evidence, media metadata, source packages, manifests, maps, documents, and large research objects outside compact chain entries.

Shared Indexes

Maintains cross-species taxonomy, geography, ecological relationship, provider, reference, bounty, release, and network indexes.

Audit Journal

Records local imports, validation decisions, peer exchanges, administrative actions, failures, repairs, migrations, and configuration changes.

Cryptographic Integrity

Hashes establish object identity and chain continuity; signatures identify authorized submitters, reviewers, publishers, and protocol releases.

Rebuildability

Indexes and materialized views are reproducible derivatives that can be rebuilt from verified chains, objects, schemas, and manifests.

Snapshot and Checkpoint Store

Preserves verified checkpoints, release snapshots, provider states, and recovery anchors for faster restoration and comparison.

Quarantine Store

Keeps invalid, incomplete, suspicious, incompatible, or policy-rejected content separate from verified local state for inspection and safe analysis.
