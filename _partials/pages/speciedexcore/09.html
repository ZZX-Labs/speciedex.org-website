Interfaces

Developer Surface

CLI

Scriptable node control, import, export, verification, synchronization, query, feed, wallet, bounty, and diagnostic commands.

Local GUI

Operator and researcher interface for node status, chains, records, validation, analysis, peers, storage, feeds, and bounties.

REST and Query APIs

Stable endpoints for search, records, blocks, objects, taxonomy, geography, feeds, validation, submissions, and node status.

Streaming Interfaces

WebSocket, Server-Sent Events, JSON Lines, local sockets, and message-bus adapters for live events and deterministic replay.

SDKs

Typed client libraries and examples for Python, C, C++, Go, JavaScript, Java, Kotlin, and other supported environments.

Plugin Adapters

Provider, storage, index, media, export, analysis, validation, and visualization adapters can evolve independently of the protocol core.

Test Harness

Deterministic fixtures, local networks, malformed-data suites, migration tests, provider mocks, and replayable validation cases.

Reproducible Builds

Pinned dependencies, signed releases, migration tests, deterministic fixtures, checksums, and public verification instructions support independent auditing.
