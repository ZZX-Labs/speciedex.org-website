Scientific and Protocol Validation

Validation Pipeline

Schema Validation

Checks required fields, types, units, enumerations, identifiers, encodings, bounds, and version compatibility.

Taxonomic Validation

Checks rank, lineage, accepted names, synonyms, source concepts, ambiguous identifications, and proposed new taxa.

Evidence Validation

Checks supporting media, references, specimens, methods, timestamps, hashes, and evidentiary sufficiency.

Geographic Validation

Checks coordinates, uncertainty, region consistency, habitat plausibility, restricted locations, and impossible movement.

Provenance Validation

Checks source identity, license, acquisition method, transformations, submitter signatures, retrieval state, and duplicate lineage.

Policy Validation

Rejects prohibited human records, privacy-invasive material, malicious payloads, unsupported licenses, and protocol-invalid content.

Conflict Analysis

Detects contradictory assertions and routes them into comparison, review, challenge, supersession, or unresolved states.

Commit Validation

Re-verifies ordering, parent linkage, signatures, consensus state, schema compatibility, and object availability before accepting an update.

Human-Exclusion Validation

Detects direct and disguised human taxa, biometric records, genomic profiles, identity graphs, and tracking-oriented submissions.

Malware and Payload Validation

Rejects executable payloads, malformed archives, path traversal, decompression bombs, hostile metadata, and unsupported object formats.
