SpeciedexCore

The open-source local and server engine that operates Speciedex nodes, validates species-chain data, synchronizes the peer-to-peer corpus, exposes APIs and feeds, and integrates Bitcoin-native incentives.

SpeciedexCore is the software foundation used to run the Speciedex protocol from a local system, research workstation, institutional deployment, field station, public server, application backend, or API gateway.

A full-weight node maintains and independently verifies a complete one-to-one, one-hundred-percent copy of the public Speciedex corpus: every permitted species chain, shared object, manifest, index, protocol record, and required archival reference.

Selective deployments may follow chosen taxa, regions, providers, media classes, research programs, or recent chain windows while retaining the verification information needed to establish the integrity and ancestry of synchronized content.

SpeciedexCore is designed around local ownership of verified data. Network access extends synchronization, submission, peer discovery, and remote services, but does not replace local validation or make one central server authoritative.

Permanent Protocol Boundary

SpeciedexCore permanently rejects Homo sapiens as a species blockchain, taxon record, observation target, specimen subject, bounty subject, biometric subject, genomic profile, or tracking target.

This exclusion is constitutional to the protocol and cannot be disabled by an operator, administrator, provider adapter, plugin, API client, or deployment profile.
