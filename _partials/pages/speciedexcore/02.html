The Local and Server Node Engine

One Engine, Multiple Systems

SpeciedexCore is designed for desktops, workstations, laptops, servers, institutional systems, embedded field stations, websites, and supported mobile or edge environments.

The same core validation and storage rules apply across deployment profiles even when available data, services, and hardware differ.

Local-First Operation

A user can search, inspect, validate, import, export, analyze, and prepare contributions locally.

Network connectivity extends synchronization and submission but does not define ownership or validity of the local dataset.

Full-Weight Mode

A full-weight server node stores and verifies a complete one-to-one copy of every permitted species blockchain and all required objects, indexes, manifests, schemas, and archival metadata.

It can independently reconstruct canonical state and serve the complete public corpus without relying on a remote data authority.

Selective Mode

Resource-constrained installations may follow selected taxa, regions, sources, media classes, research programs, or recent chain windows.

Selective nodes retain cryptographic verification paths, manifests, checkpoints, and source lineage for the content they hold.

Mirror and Archive Mode

Institutional mirrors and archival nodes can prioritize preservation, release verification, historical snapshots, provider packages, and long-term recovery.

Application Backend Mode

Local and remote applications can use SpeciedexCore as a trusted backend for search, validation, maps, analysis, submissions, bounties, and feeds.
