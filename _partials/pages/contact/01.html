Contact Speciedex.org

A public contact directory for general questions, technical support, documentation, research, security, media, legal, partnership, contribution, and project-development inquiries.

The Contact page is designed to route each inquiry to the appropriate project address. It does not repeat the global header, project overview, or documentation index. Its purpose is practical: help visitors identify the correct contact channel, provide enough context for a useful response, and avoid sending sensitive or specialized material to the wrong mailbox.

Speciedex welcomes questions, technical discussions, documentation corrections, scientific feedback, security reports, partnership proposals, media requests, licensing questions, contribution offers, and other project-related communication.

Before writing, review the contact categories below and use the most specific address available. Messages should clearly state the subject, affected page or software component, relevant version or dataset, links or identifiers, supporting evidence, and the action or response being requested.

Security vulnerabilities, privacy concerns, sensitive biodiversity data, unpublished research, legal notices, and confidential partnership information should be sent only to the designated channel for that subject.

Choose the Right Address

General, support, documentation, research, security, media, legal, partnership, and contribution inquiries each have a dedicated contact route.

Provide Useful Context

Include affected URLs, software versions, provider names, record identifiers, screenshots, logs, citations, or reproduction steps when relevant.

Protect Sensitive Information

Do not place vulnerabilities, private data, restricted species locations, or confidential legal material in a general inquiry.

Review Existing Resources

Documentation, release notes, FAQs, legal notices, and project resources may already answer common questions.
