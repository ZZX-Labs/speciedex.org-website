Protocol Model

A Blockchain for Every Species

Independent Species Chains

Each permitted species is represented by a singular append-only blockchain containing the ordered history of accepted submissions, corrections, observations, evidence, source imports, taxonomic changes, disputes, and validation decisions associated with that species.

Species chains remain independently addressable while sharing common protocol rules, schemas, cryptographic verification, peer discovery, network transport, validation states, and archival formats.

Shared Reference Objects

Publications, media, specimens, geographic objects, genetic references, provider records, and taxonomic concepts may be referenced across many species chains without duplicating the complete underlying object.

Shared references retain hashes, source identifiers, licenses, provenance, version information, and availability metadata.

Canonical State and Historical State

Nodes can derive the current canonical state of a species while still preserving earlier assertions, competing interpretations, retracted records, review outcomes, and superseded classifications.

Canonical state is therefore computed from history rather than used to erase history.

The Complete Speciedex

The complete Speciedex is the verified union of all permitted species blockchains, taxonomic indexes, shared reference objects, manifests, source records, protocol metadata, and public releases.

A full-weight server node maintains a one-to-one, one-hundred-percent copy of this public corpus and can independently verify and serve it.
