SpeciedexWeb

The public browser gateway for viewing, searching, comparing, watching, learning from, and exporting verified biodiversity records from the decentralized Speciedex species-chain corpus.

SpeciedexWeb is designed for people who need immediate access to Speciedex data without installing, storing, synchronizing, securing, or maintaining a local node. It presents browser-based search, species profiles, taxonomy, maps, research records, media, chain history, live validation activity, bounties, and reproducible exports.

The website is served from one or more SpeciedexCore gateway or full-weight nodes participating in SpeciedexNet. It is an access layer over the decentralized corpus, not the owner of that corpus and not a substitute for independent node verification.

Every important view should expose enough context for users to understand which node or gateway served it, how current the data is, which chain state or release it represents, which sources support it, and whether unresolved scientific disagreement remains.

Core reading and navigation should remain functional with minimal JavaScript. Advanced maps, timelines, playback controls, feeds, dashboards, filters, and analysis progressively enhance the base document.

Permanent Safety Boundary

Homo sapiens is not present and cannot be entered, searched, tracked, profiled, mapped, or represented as a species record.

The public gateway must never become a human biometric, location-history, genomic-profiling, identity-correlation, or surveillance interface.
