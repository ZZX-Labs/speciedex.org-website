Data Confidence and Provenance

Current Canonical View

The default page presents the current accepted network state while clearly labeling confidence, age, source coverage, uncertainty, and unresolved conflicts.

Source-Level Inspection

Every significant claim can be opened to inspect the originating submission, provider record, evidence, validation result, chain position, license, and later revisions.

Historical View

Users can select a block height, date, release, provider state, or event to reconstruct an earlier species record.

Gateway Transparency

The site identifies the serving node or gateway pool, synchronization status, chain tips, software version, data release, and verification scope.

Conflict Visibility

Competing classifications, contradictory records, unresolved reviews, and source disagreements remain visible instead of being silently flattened.

Stable Citations

Current and historical views can produce citations that identify the chain state, release, query, serving context, and referenced source objects.
