Purpose

The Public Browser Gateway

Access Without Operating a Node

SpeciedexWeb gives users immediate browser access to verified Speciedex data when they cannot or do not wish to install, store, synchronize, maintain, secure, or expose a node.

Backed by Real Nodes

The website reads from one or more SpeciedexCore gateway or full-weight nodes. It is an access service over the decentralized dataset, not a replacement for SpeciedexNet.

Read and Explore

Users can view species profiles, chain history, taxonomy, observations, maps, media, conservation records, sources, citations, and validation state.

Analyze and Learn

Browser tools support filters, comparisons, timelines, educational views, dashboards, exports, and reproducible links within web constraints.

Gateway Transparency

Serving-node identity, synchronization status, chain tips, software version, release state, and freshness indicators remain visible where practical.

Portable Public Access

The interface can be served by independent mirrors, institutions, archives, regional operators, or offline packages without changing the underlying protocol.
