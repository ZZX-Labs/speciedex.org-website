Versioned Preservation

Release and Snapshot Model

Stable Releases

Reviewed public packages with fixed manifests, checksums, schemas, release notes, and compatibility declarations.

Candidate Releases

Pre-release packages preserved for testing, comparison, validation, migration rehearsal, and issue review.

Provider Snapshots

Time-bounded copies of provider data and documentation tied to retrieval state and transformation history.

Chain Checkpoints

Verified chain tips and inventories that accelerate bootstrap while remaining checkable against complete history.

Historical Releases

Superseded public datasets, earlier classifications, outdated schemas, and prior software preserved for reproducibility.

Development Snapshots

Clearly labeled experimental packages containing active work, unresolved issues, and potentially incompatible changes.

Partial Collections

Taxon, region, provider, media, literature, or research subsets with explicit scope and dependency metadata.

Offline Mirrors

Portable packages suitable for removable media, controlled physical transfer, disconnected institutions, and disaster recovery.
