Verification

Integrity, Manifests, and Checksums

Immutable Manifests

Record file paths, sizes, hashes, media types, object roles, dependencies, schema versions, release identifiers, and timestamps.

Cryptographic Checksums

Verify individual files, archive bundles, database products, documentation sets, media objects, and complete releases.

Digital Signatures

Authenticate official releases, provider snapshots, manifests, schemas, software packages, and migration artifacts.

Chain Verification

Confirm species-chain ancestry, block identity, signatures, checkpoints, object references, and canonical state.

Independent Rebuilds

Regenerate indexes, exports, reports, statistics, and derived databases from preserved primary materials.

Corruption Detection

Detect missing files, altered content, truncated objects, mismatched manifests, invalid signatures, and archive drift.
