Node Roles

Full-Weight Node

Stores and verifies every permitted species blockchain, shared object set, manifest, schema, release, and required index.

Archive Node

Preserves historical blocks, releases, source packages, evidence objects, software, manifests, and recovery materials.

Regional Node

Prioritizes selected geography, languages, field programs, ecosystems, institutions, and locally relevant species.

Selective Node

Follows chosen species, taxa, providers, media classes, projects, or chain windows while verifying received content.

Gateway Node

Provides controlled APIs, feeds, queries, caching, and browser services to clients that do not operate nodes.

Relay Node

Improves peer reachability and propagation without necessarily exposing public search or application services.

Media Node

Stores and serves licensed content-addressed images, audio, video, scans, models, maps, and approved derivatives.

Field Node

Operates during intermittent or disconnected conditions and synchronizes signed packages when connectivity returns.

Validation Node

Prioritizes schema, taxonomy, provenance, evidence, policy, conflict, and chain-state verification workloads.

Bootstrap Node

Provides signed inventories, checkpoints, peer references, and initial synchronization material without becoming authoritative.
