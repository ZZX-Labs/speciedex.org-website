Lightning Implementations

LND

LND is an open-source Lightning implementation developed by Lightning Labs.

It provides node operation, wallet functions, channel management, routing, invoices, payments, APIs, and integration with Bitcoin backends.

View LND ↗

Core Lightning

Core Lightning is an open-source Lightning implementation maintained by Blockstream and a broader contributor community.

It emphasizes modularity, extensibility, plugins, and close integration with Bitcoin Core.

View Core Lightning ↗

Eclair

Eclair is an open-source Lightning implementation developed by ACINQ.

It supports Lightning nodes, channels, routing, payments, and production payment infrastructure.

View Eclair ↗

Lightning Development Kit

Lightning Development Kit provides modular libraries for developers building custom Lightning wallets, nodes, payment systems, and applications.

Developers can select and integrate Lightning components within their own software architecture.
