Start With the Interface That Fits Your Work

Browse and Learn

Use Speciedex, SpeciedexWeb, and SpeciedexExplorer for species pages, taxonomy, visual discovery, maps, references, and public learning.

Research and Analyze

Use SpeciedexLibrary, SpeciedexAnalysis, SpeciedexMaps, and SpeciedexGeneticBank for evidence, comparison, geography, and genetics.

Build and Integrate

Use SpeciedexCore, SpeciedexTerminal, SpeciedexAPI, schemas, downloads, and source documentation to build new tools and institutional services.

Preserve and Operate

Use SpeciedexNet and SpeciedexArchives to run mirrors, verify releases, preserve datasets, and support long-term public availability.

Speciedex supports different kinds of work through different interfaces. Public visitors can begin with species browsing and visual exploration. Researchers can continue into literature, maps, genetics, provider provenance, and analysis. Developers can use terminal tools, core libraries, downloads, schemas, and APIs. Institutions can examine mirrors, archives, preservation, partnerships, and distributed operation.
