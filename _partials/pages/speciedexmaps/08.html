Interoperability

Exports, Services, and Reproducibility

GeoJSON

Export permitted points, lines, polygons, properties, uncertainty, provenance, and identifiers.

CSV and TSV

Export flat spatial records for statistical, spreadsheet, scripting, and institutional workflows.

Map Images

Export publication or presentation images with scale, legend, attribution, projection, date, and source notes.

Tile and Feature Services

Serve documented map tiles, vector features, layers, and query responses from approved Speciedex nodes or gateways.

Query Definitions

Preserve filters, bounds, time, taxonomy, providers, release, chain state, ordering, and selected fields.

Map Manifests

Record layer inventories, checksums, styles, licenses, dependencies, data releases, and generation metadata.

Offline Packages

Package selected maps, taxa, guides, layers, schemas, and metadata for field use through SpeciedexApp or local tools.

Citable State

Cite serving node, release, chain state, query, projection, layer set, generation time, and restricted-data policy.
