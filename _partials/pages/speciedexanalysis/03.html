Scientific Work

Primary Analysis Domains

Taxonomic Analysis

Compare names, authorities, ranks, lineages, synonyms, competing classifications, splits, mergers, and historical placements.

Provider Analysis

Measure coverage, overlap, uniqueness, update age, errors, rejected records, licenses, transformations, and dependence.

Distribution Analysis

Measure occurrence density, geographic range, sampling gaps, uncertainty, introduction, contraction, expansion, and temporal change.

Trait Analysis

Compare measurements, morphology, diagnostic characters, life histories, developmental stages, variation, and confidence.

Ecological Networks

Analyze predation, pollination, host, parasite, symbiotic, competitive, habitat, and food-web relationships.

Conservation Analysis

Compare assessments, threats, protection, population trends, observation frequency, habitat loss, and evidence age.

Genetic Reference Analysis

Measure accession coverage, voucher completeness, marker availability, taxonomic conflicts, repository state, and metadata quality.

Literature Analysis

Analyze citation networks, source coverage, claim support, publication history, methods, corrections, and research gaps.

Chain-State Analysis

Study submissions, validation, commits, revisions, retractions, conflicts, checkpoints, and canonical-state change.

Network Analysis

Measure peer coverage, synchronization lag, object availability, release compatibility, provider reach, and gateway health.
