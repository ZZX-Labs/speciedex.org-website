Purpose

A Direct Interface to Speciedex Infrastructure

Interactive Console

Enter commands, inspect results, review help, use history, complete command names, and follow live system state in one persistent terminal session.

Command-Line Client

Run one command at a time from a shell, script, scheduled task, service unit, CI workflow, or institutional automation system.

Local Node Control

Connect directly to a user-owned SpeciedexCore node for private, offline, low-latency, and independently verified operation.

Remote Gateway Access

Query trusted read-only or authenticated remote services when operating a complete local node is impractical.

Research Workbench

Combine searches, filters, comparisons, exports, citations, chain history, provider differences, and reproducible query state.

Administrative Surface

Perform privileged tasks only through authenticated, least-authority interfaces separated from ordinary public queries.
