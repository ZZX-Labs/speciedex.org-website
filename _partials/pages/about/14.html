Long-Term Roadmap

A staged path from foundational data systems to durable, independently operated global biodiversity infrastructure.

The roadmap is organized by capability rather than by isolated product. Core schemas, identifiers, provider pipelines, archives, maps, analysis, APIs, applications, and mirrors reinforce one another and should mature as a coordinated system.

Foundation

  • Project architecture and repository structure
  • Public website and page-component framework
  • Core schemas, identifiers, and provider provenance
  • Import, normalization, validation, and export tools
  • Initial release, checksum, signature, and archive process
  • Provider documentation and license records

Expansion

  • Comprehensive search and browsing
  • Multi-provider taxonomy reconciliation
  • Literature, media, specimen, and genetic indexing
  • SpeciedexLibrary, SpeciedexAnalysis, and SpeciedexMaps
  • Versioned public APIs and developer tools
  • Desktop, mobile, field, and offline application access

Network

  • Independent mirrors and synchronization
  • Signed manifests and distributed integrity verification
  • Institutional archival partnerships
  • Offline and low-bandwidth deployments
  • Global contributor and review infrastructure
  • Bitcoin and Lightning funding and operator services

Permanent Infrastructure

  • Comprehensive global taxonomic coverage
  • Long-term public preservation and reproducible reconstruction
  • Multilingual interfaces and educational tools
  • Research, conservation, and government integrations
  • Independent ecosystem governance
  • Intergenerational continuity across organizations and technologies
