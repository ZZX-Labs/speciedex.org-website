Open Source and Licensing

Licensing information is part of provenance. Exports and public records should retain attribution, source URLs, provider names, license notices, usage restrictions, and any known incompatibilities that affect redistribution or derivative work.

Individual datasets, media, publications, taxonomic references, photographs, recordings, genetic records, and other third-party materials may use different licenses or restrictions. The project must preserve those terms rather than treating all imported material as if it inherited the software license.

Speciedex software is developed as open-source software. Unless otherwise noted, project-controlled source code is released under the MIT License so it can be inspected, reused, modified, archived, and independently maintained.

Software

MIT-licensed project code with public repositories, release archives, version history, checksums, and signatures.

Documentation

Public documentation intended to remain accessible, versioned, attributable, and suitable for long-term archival.

Data

Individual datasets retain their respective licenses, attribution requirements, provider terms, and usage restrictions.

Media

Images, illustrations, audio, and video remain subject to the licenses and permissions associated with their creators and source institutions.

Research Publications

Papers, books, reports, and citations remain governed by their publishers, authors, repositories, and applicable open-access terms.

Derived Products

Normalized exports and indexes should document which portions are original project work and which remain constrained by upstream rights.
