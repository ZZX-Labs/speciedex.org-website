Contributing

Contributions are welcomed across science, software, documentation, data stewardship, infrastructure, education, preservation, and public service.

Contributions should preserve scientific provenance, respect licensing and ethical restrictions, remain reviewable, and improve the long-term public utility of the project. A useful contribution can be as small as correcting one record or as large as operating an institutional mirror, integrating a collection, or maintaining an entire platform.

Speciedex is intended to be a long-term community and institutional project. Contributions may involve software engineering, taxonomy, biology, ecology, genetics, conservation, mapping, literature, documentation, translation, accessibility, testing, security, infrastructure, education, or public outreach.

Develop Software

Build core libraries, APIs, search, terminal tools, applications, imports, synchronization services, maps, analysis, and infrastructure.

Improve Data

Assist with taxonomy, validation, provenance, references, geographic records, genetics, conservation data, and provider reconciliation.

Write Documentation

Improve manuals, provider references, tutorials, architecture notes, policies, educational material, translations, and contributor guides.

Review and Test

Evaluate releases, schemas, migrations, scientific mappings, accessibility, security, performance, and public interfaces.

Operate Infrastructure

Run mirrors, preserve releases, host services, verify manifests, maintain archives, and support resilient SpeciedexNet operation.

Support the Project

Fund development, sponsor archives, provide institutional partnerships, donate, share expertise, or contribute equipment and hosting.
