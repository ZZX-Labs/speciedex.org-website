# Speciedex scientific-name lookup products

Generated by `static/tools/lookups/build-all-species-lookups.py`.

The normalized scientific name is the lookup key. Canonical taxonomy volumes are
walked once, one species/subspecies record at a time. Provider revision data is
merged only when the Speciedex ID resolves to that canonical record and the
provider assertion's scientific/canonical name is compatible with the canonical
name.

Generated indexes:

- `scientific-names.json`
- `common-names.json`
- `canonical-names.json`
- `authorship.json`
- `provider-sources.json`
- `dates.json`
- `taxonomy.json`
- `synonyms.json`
- `status-rank.json`
- `display-classes.json`
- `manifest.json`

These files are generated products. Purge them with
`python static/tools/lookups/purge-lookups.py --yes` and rebuild them through the
single `Rebuild Speciedex Species Lookups` workflow or locally with
`python static/tools/lookups/build-all-species-lookups.py`.
