# Provider Example Records

This directory contains one representative JSON example for each configured
provider. Examples support mapping development, schema validation,
normalization tests, documentation, and edge-case handling without requiring a
live request.

Files must share identifiers with provider adapters, schemas, policies, tests,
and documentation. Keep examples small, reproducible, license-compatible, and
free of credentials. Use clearly labeled synthetic records when redistribution
of real provider data is not allowed. Examples are not production taxonomy.
