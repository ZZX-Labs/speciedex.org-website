## Required asset record

Before an image is used, document:

- filename;
- creator/photographer;
- original title;
- canonical source URL;
- license and license URL;
- retrieval date;
- modifications/cropping;
- pages that use the asset;
- optional checksum and dimensions.

## Rules

- Use real PNG/JPEG/WebP files, not empty placeholders.
- Keep licensing and attribution verifiable.
- Do not commit copyrighted assets without permission or an applicable license.
- Optimize images for the web while retaining a documented source master where appropriate.
- Use descriptive lowercase filenames for new assets when practical.
- Add meaningful `alt` text in HTML; do not store accessibility text only in this README.
