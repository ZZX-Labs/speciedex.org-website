# Project Images

This directory groups images by Speciedex project or product. Each child
directory documents its own inventory, dimensions, intended placements, and
known missing or placeholder assets.

The `speciedex/` directory contains project-specific terminal/loading imagery.
Product logos belong in `static/logos/`; general imagery belongs under
`static/images/`; deterministic taxonomic icons belong in
`static/images/taxa/`.

Use stable lowercase filenames and valid content matching the extension.
Animation sequences require consistent canvas size, framing, background, and
ordering. Empty or two-byte placeholder files must not be published.
