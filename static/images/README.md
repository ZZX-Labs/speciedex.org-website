# Bitcoin Address Images

This directory contains PNG address images used by donation and payment pages.
Each filename is a Bitcoin address and the image must encode or display exactly
that same address.

Verify every image against its filename and the corresponding HTML before
publication. A mismatch can redirect funds and is release-blocking. Preserve a
clean quiet zone, avoid smoothing or overlays inside code modules, use lossless
PNG, and never store private keys, seeds, descriptors, or wallet metadata here.
