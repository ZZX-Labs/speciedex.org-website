# Navigation Icons

This directory contains icons used by the header, navigation menus, product
navigation, and mobile navigation. `manifest.json` catalogs stable semantic
names such as home, project, products, documentation, downloads, bitcoin,
resources, and projects.

Assets must remain consistent with the Speciedex dark interface, transparent
backgrounds, compact geometry, and small-size legibility. They should not
duplicate full product logos in `static/logos/` or taxonomic icons in
`static/images/taxa/`. Update the manifest whenever files change.
